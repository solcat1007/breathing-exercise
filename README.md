# 呼吸练习 (Breathing Exercise)

一个简洁的呼吸练习网页应用，通过圆形动画引导用户进行有节奏的深呼吸训练，帮助放松身心、缓解压力。

## 功能特性

- **三种呼吸模式**
  - **4-7-8 呼吸法**：吸气 4 秒 → 屏息 7 秒 → 呼气 8 秒，共 4 轮
  - **盒式呼吸**：吸气 4 秒 → 屏息 4 秒 → 呼气 4 秒 → 放松 4 秒，共 5 轮
  - **4-4-4-4 呼吸法**：吸气 4 秒 → 屏息 4 秒 → 呼气 4 秒 → 放松 4 秒，共 4 轮
- **可视化引导**：Canvas 绘制的圆形动画，吸气时圆弧增长，呼气时圆弧缩减，直观跟随
- **中英文切换**：支持中文和英文界面，点击左上角按钮即可切换
- **全屏模式**：专注练习时一键进入全屏
- **计时提示**：每个阶段显示剩余秒数，节奏清晰
- **轮次计数**：实时显示当前练习轮次

## 使用方法

1. 直接在浏览器中打开 `index.html`
2. 选择呼吸模式（默认 4-7-8）
3. 点击「开始」按钮，跟随动画提示进行呼吸
4. 练习过程中可随时点击「停止」结束

## 技术实现

- 纯前端实现，无需任何依赖或构建工具
- HTML5 Canvas 绘制呼吸动画
- 原生 JavaScript 控制呼吸节奏与状态切换
- 响应式设计，适配桌面和移动端
